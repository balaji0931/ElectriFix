# ElectriFix

ElectriFix is an operator console for detecting and managing electricity distribution faults. Phase 0 provides the runnable project skeleton; feature documentation will be completed in Phase 19.

## Local Startup

With Docker installed, run:

```sh
docker compose up --build
```

Open `http://localhost:8080` for the client shell. Verify the server at `http://localhost:8080/api/health`.

See `DEPLOYMENT.md` for prerequisites and Phase 0 troubleshooting.
